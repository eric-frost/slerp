Thumbnails and a viewer for 3D and game files.

Slerp makes file-manager thumbnails for about 200 kinds of 3D, game and graphics files, and opens them in a viewer that orbits models, walks through levels and shows the pieces each file is made of.

What it does

Thumbnails and a viewer.

Slerp makes the thumbnails your file manager shows, and opens files in its own viewer. Both use the same file readers and the same GPU renderer.

Thumbnails

Thumbnails in the file manager.

On Linux, Slerp works with Dolphin, GNOME Files, Nemo, Caja, Thunar and PCManFM-Qt through the freedesktop thumbnailer standard. On Windows it adds a thumbnail handler to Explorer, and on macOS a Quick Look extension for Finder.

Starting a GPU takes 100 to 800 ms, too long to pay for each file. So the first thumbnail starts a helper process that keeps the GPU loaded. On a laptop with an RTX 5070 Ti, each thumbnail after that took a few milliseconds. The helper quits after two idle minutes.

Viewer

One viewer for models, levels, textures and skies.

Slerp picks a view from the file. Models get an orbit camera. Levels from Quake, Half-Life and Doom open in first person at the player's start. Textures show their mip levels, cube faces, array layers and colour channels. Skies, splats, materials, sprite sheets, toolpaths and CT and MRI scans each get a view of their own.

The renderer is Slerp's own, built on wgpu: Vulkan on Linux, Direct3D 12 on Windows and Metal on macOS. It draws the copies of one mesh together, in one call. On a laptop with an RTX 5070 Ti, that took a USD scene of 100,000 trees from 73.6 ms a frame to 3.4 ms, in a 1600x1000 window.

Animation

Play and retarget animations.

Pick any clip a character carries, play it, scrub through it or step it a frame at a time. Add Animations from File plays the clips of a separate animation library on the character you are looking at, matched by joint names or retargeted between humanoid skeletons.

Foot IK keeps planted feet on the ground when a character's legs are shaped differently from the ones the clip was made for. Blend shapes, VRM expressions and MetaHuman face controls move live.

Contents

The pieces inside a file.

The Contents panel lists what a file is made of: nodes, meshes, materials, textures, clips, skeletons, layers and archive entries. Click one to see it on its own, or hover it to outline it in the 3D view.

Drag any piece out of the window and it lands as an ordinary file: textures as PNG or EXR, meshes and clips as GLB, sounds as WAV. What Slerp opens in 3D can be saved as glTF, from the viewer or with slerp convert, and Slerp's tests check the output with the Khronos glTF Validator.

Slerp reads and extracts, and never changes your files.

Safety

Careful with what it reads.

A thumbnailer opens the files you scroll past, downloads included, so Slerp trusts none of them. Its readers check sizes and offsets before using them, cap how much memory a file can ask for, and are meant to turn a damaged file into a message rather than a crash. That lowers the risk of a bad file without ruling it out.

  • Fuzzed. 38 cargo-fuzz targets feed the parsers broken and random input. The crashes and hangs found so far are fixed, each with a regression test.
  • Kept apart. The riskier C decoders and the PDF and SVG renderers run in separate processes with time and memory limits.
  • Offline. Slerp never goes online: no accounts, no telemetry, no update checks.

Desktop

The desktop's look.

The viewer takes its colours, fonts and icons from KDE, GNOME, Windows or macOS. Which files it opens when you double-click them depends on the system:

  • Linux. Slerp opens the formats nothing else on your computer opens. For ordinary pictures it waits under Open With, below your usual image viewer.
  • Windows. Slerp appears under Open with. Only you can make it the default app, in Settings, Default apps, Slerp.
  • macOS. Slerp opens the formats macOS doesn't know, and OBJ, STL, PLY, COLLADA and USDA. GLB, USDZ, KTX, DDS, HDR and PNG stay with Preview.

Change it for any format in the viewer's settings or with slerp associate. slerp associate --reset puts back exactly what was there before.

Formats

About 200 formats in 16 categories.

From glTF, FBX and USD to Quake maps, KTX2 textures, Gaussian splats, DICOM scans and Commodore 64 pictures. Search for yours, or pick a category.

For many formats Slerp reads only part of what the format can hold; docs/format-details.md says what each reader leaves out. Ordinary pictures such as PNG and JPEG open in the viewer, but Slerp leaves their thumbnails to your desktop unless you switch its own on. Animation files have no thumbnail of their own: there is nothing to draw until a character plays them.

Install

Install Slerp.

0.1.0 is the first release. Its files are on the Releases page, with their checksums in SHA256SUMS. The Windows and Mac builds aren't signed with a certificate, so each warns the first time; the steps are below.

Linux

Download

Each distribution gets two packages: slerp, and the optional slerp-qt-plugin, which lets Gwenview and Dolphin's Information panel show Slerp's formats. The names here are for x86_64; on arm64 they end in arm64.deb, aarch64.rpm and aarch64.tar.gz.

Open the Releases page

Debian and Ubuntu

Debian 12 or newer, Ubuntu 22.04 or newer. apt fetches what the packages need.

sudo apt install ./slerp_0.1.0-1_amd64.deb \
  ./slerp-qt-plugin_0.1.0-1_amd64.deb

Fedora

dnf fetches what the packages need.

sudo dnf install ./slerp-0.1.0-1.x86_64.rpm \
  ./slerp-qt-plugin-0.1.0-1.x86_64.rpm

Arch Linux

x86_64 only.

sudo pacman -U slerp-0.1.0-1-x86_64.pkg.tar.zst \
  slerp-qt-plugin-0.1.0-1-x86_64.pkg.tar.zst

Other distributions

Unpack slerp-0.1.0-linux-x86_64.tar.gz and run this in it. It installs under /usr/local, and --uninstall removes it again. GNOME's file managers need --prefix /usr, because their thumbnail sandbox sees only /usr.

sudo ./install.sh

Then, in Dolphin

Most file managers find Slerp by themselves. Dolphin keeps its own list of preview plugins, so run this once for each user, then restart Dolphin:

slerp associate --apply

Windows

1. Download

The installer is for Windows 10 and 11 on x64. It installs Slerp for your account only, without administrator rights, sets up Explorer's thumbnails and Open with, and adds the viewer to the Start menu.

Download the installer

2. Get past SmartScreen

The installer isn't signed, so SmartScreen says "Windows protected your PC". Click "More info", then "Run anyway". If Smart App Control is switched on, Windows blocks unsigned programs outright, and Slerp can't be installed.

3. Done

Explorer shows thumbnails of Slerp's formats, and Slerp appears under Open with. Settings, Apps, Installed apps removes Slerp again, and puts back any thumbnail handler it replaced.

Without the installer

Slerp-windows-x64.zip holds the same programs. Unpack them into a folder that stays put and run this there once, without administrator rights. slerp.exe unregister undoes it.

slerp.exe register

macOS

1. Download

For macOS 11 or newer on Apple Silicon; Intel Macs aren't supported. Open the disk image and drag Slerp to Applications. The app holds the viewer and a Quick Look extension that gives Finder thumbnails of the formats macOS doesn't know.

Download the disk image

2. First start

The app is signed ad hoc but not notarized by Apple, so macOS blocks it the first time you open it. Then open System Settings, Privacy & Security, click "Open Anyway" beside the message about Slerp, and confirm. Finder shows Slerp's thumbnails once the app has been opened.

Or from Terminal

This avoids the warning, since curl doesn't mark what it downloads as coming from the internet. The same command updates Slerp later: it replaces the app that is there.

curl -fL -o /tmp/Slerp.zip \
  https://github.com/eric-frost/slerp/releases/latest/download/Slerp-macos-arm64.zip &&
  rm -rf /Applications/Slerp.app && ditto -x -k /tmp/Slerp.zip /Applications &&
  open /Applications/Slerp.app

From source

What you need

Rust 1.93 or newer, a C and C++ compiler, libclang, and the Wayland and xkbcommon development files. On Debian and Ubuntu:

sudo apt install cargo libclang-dev libwayland-dev \
  libxkbcommon-dev pkg-config g++

Build

The README says where each installed file goes, and which Cargo features to drop for a smaller, thumbnailer-only build.

git clone https://github.com/eric-frost/slerp
cd slerp
cargo build --release

Questions

Good to know.

Anything else? Ask on GitHub.

Is it free?

Yes. Slerp is open source, under your choice of the MIT licence or the Apache License 2.0. Use it at home or at work, read the code, change it and pass it on.

Does it go online?

No. Slerp never connects to the internet. There is no account, no telemetry and no update check. It reads the file on your disk and draws it on your own computer.

Why doesn't it make thumbnails of PDFs?

Slerp is for graphics, not documents. It leaves thumbnails of PDFs, PNGs and JPEGs to your desktop unless you switch its own on. The viewer still opens ordinary pictures such as PNG and JPEG.

Does it need a graphics card?

No. Without a GPU driver, Slerp draws 3D thumbnails on the CPU, with Mesa's lavapipe on Linux and Direct3D's WARP renderer on Windows. It is slower, but it works.

Who makes it, and how far along is it?

One developer, Eric, who vibe coded it: AI coding agents wrote all of the code, the tests included, from his descriptions, and he never looked at the code himself. Slerp is a young project, and 0.1.0 is its first release. For many formats it reads only part of what the format can hold, and most of the testing so far has been on one Linux laptop with KDE, a Windows 11 virtual machine and one Mac, so expect files it gets wrong. Bug reports are welcome on GitHub, most of all with a file you are free to share.

Why the name?

Slerp is short for spherical linear interpolation, the formula 3D programs use to turn smoothly from one rotation to another. Turning things around smoothly is most of what a 3D viewer does.
